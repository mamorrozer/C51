# QG 51 塔防游戏（简化版植物大战僵尸）

## 1. 硬件接线（按此接最稳）
- I2C1（软件 I2C，OLED/AT24C02）：SCL=P0.0，SDA=P0.1
- OLED SSD1306（I2C1）：SCL=P0.0，SDA=P0.1
- AT24C02（I2C1）：SCL=P0.0，SDA=P0.1
- 4x4 矩阵键盘：
  - 行线：P1.7、P1.6、P1.5、P1.4
  - 列线：P1.3、P1.2、P1.1、P1.0
- 重要：P0 口为开漏，I2C1 的 SCL/SDA 必须外接上拉（4.7kΩ~10kΩ）。
- 蜂鸣器：P2.5

## 2. 操控说明（矩阵键盘）
- 方向移动（十字区）：`6=上`、`14=下`、`9=左`、`11=右`
- 第1排工具键：`1=射手`、`2=坚果墙`、`3=铲除`
- 确认/执行当前工具：`10`
- 把光标移动到最左列（每行开头的 `S/W`），按 `10` 选择工具
  - 第1行 `S` = 射手，第2行 `W` = 坚果墙
- 在战场区域按 `10`：执行当前工具
- 战场中的玩家光标显示为 `+`（十字）
- 成功种植后，光标会短暂隐藏约 0.5 秒，先显示新植物，再恢复光标
- `13`：暂停/继续
- `16`：返回结算
- 游戏内顶部为精简显示：`T(当前工具) + H(生命) + R(资源)`

## 3. 玩法说明
- 流程：开始页 -> 选难度（EASY/HARD）-> 进入战斗。
- 2 条轨道，敌人从右向左移动（每轨显示宽度 16 列）
- 植物：
  - `W` 坚果墙：高血量，专门阻挡
  - `S` 射手：会自动发射 `*` 子弹
- 敌人：
  - `z` 普通敌人（慢，血高）
  - `Z` 快速敌人（再次降速）
- 子弹与敌人同格时命中，敌人血量归零后消失并加分
- 敌人到达最左侧会扣基地生命 `H`
- 生存到目标时间判定胜利，生命归零判定失败
