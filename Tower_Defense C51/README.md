# 51单片机塔防游戏机 - 操作说明书

> 本项目为 3 轨道实时塔防：支持普通模式与特殊模式，难度为 EASY/HARD 两档。

## 特殊模式特点（先看这个）
- 有迷雾：迷雾会从右向左慢慢扩散，最多覆盖右半屏。
- 有技能：光标停在已种植物上按 `10` 可放技能（会消耗阳光）。

## 一、产品简介
本项目为一款基于51单片机（STC89C52RC）打造的便携式实体塔防游戏机。受限于单片机内存，游戏画面采用 ASCII 字符显示，但完整保留了策略塔防的核心玩法（类似简化版《植物大战僵尸》）。设备支持脱离电脑独立运行，内置双难度、掉电存档、非阻塞音效及迷雾模式。

## 二、硬件连接与开机说明
本机基于普中开发板魔改，已外接 DC-DC 独立供电模块，**无需插接 USB 线即可作为掌机运行**。

1. **开机**：拨动开发板上的电源开关，OLED 屏幕亮起即进入游戏。
2. **外设确认**：请确认矩阵键盘插在对应接口，蜂鸣器已连接。

## 三、按键操作映射（矩阵键盘）
- 方向移动（十字区）：`6=上`、`14=下`、`9=左`、`11=右`
- 第1排工具键：`1=射手`、`2=坚果墙`、`3=铲除`
- `4`：直接铲除光标所在格植物
- 确认/执行当前工具：`10`
- 把光标移动到最左列（每行开头的 `S/W/R`），按 `10` 选择工具
  - 第1行 `S` = 射手，第2行 `W` = 坚果墙，第3行 `R` = 铲除
- 在战场区域按 `10`：执行当前工具
- 战场中的玩家光标显示为 `+`（十字）
- 成功种植后，光标会短暂隐藏约 0.5 秒，先显示新植物，再恢复光标
- `13`：暂停/继续
- `16`：返回结算
- 游戏内顶部显示：`T(当前工具) + H(生命) + R(资源) + S(分数)`
- 开始页可选择是否进入特殊模式：
  - `6/14`：切换 `SPECIAL:OFF/ON`
  - `10`：进入难度选择页
- 难度选择页右半边会显示“当前选中难度”的历史最高分（EASY/HARD 分别记录）
**- 历史最高分保存在 AT24C02 EEPROM，断电后不会丢失**

## 四、玩法说明
- 流程：开始页 -> 选难度（EASY/HARD）-> 进入战斗。
- 两档参数：
  - EASY：`life=10`，`spawn_interval=16`，`enemy_move_step=4`，`target_tick=500`
  - HARD：`life=6`，`spawn_interval=9`，`enemy_move_step=3`，`target_tick=700`
- 3 条轨道，敌人从右向左移动（每轨显示宽度 16 列）
- 三条轨道的刷怪与敌人强度规则一致，观察与操作逻辑统一
- 支持长按按键连续移动（例如光标连续上下/左右移动），属于操作特性的一部分
- 这样设计的原因是矩阵键盘在实机上反馈偏慢，通过长按连发提升体感灵敏度与操作效率
- 特殊模式（SPECIAL:ON）：
  - 迷雾会从右向左逐步蔓延，最多覆盖右半屏（8 列）
  - 光标停在已种植物上再按 `10` 可释放植物技能
- 植物：
  - `W` 坚果墙：高血量，专门阻挡
  - `S` 射手：会自动发射 `*` 子弹
- 植物技能（特殊模式下）：
  - 射手技能：瞬发多发豌豆（消耗阳光 `15`）
  - 坚果墙技能：击退附近僵尸（消耗阳光 `20`）
- 敌人：
  - `z` 普通敌人（慢，血高）
  - `Z` 快速敌人（再次降速）
- 子弹会做“贴脸+移动后”双阶段命中判定，避免近距离漏判
- 射手只会检测前方一定范围内的僵尸（当前为 6 格）
- 豌豆命中后会立即消失，不会穿透多个僵尸
- 特殊模式下，迷雾区域的僵尸不会被射手索敌
- 敌人到达最左侧会扣基地生命 `H`
- 生存到目标时间判定胜利，生命归零判定失败

## 五、 声音提示（无源蜂鸣器）
- 放置植物有提示音，且区分类型：
  - 放置射手：短单音
  - 放置坚果墙：双音
- 僵尸啃食植物会有持续提示音；植物被啃掉时提示更强
- 僵尸突破并导致扣血时有特殊强提醒音

## 六、常见问题排查 (FAQ)
**Q: 开机后屏幕不亮/乱码？**
A: 检查独立供电模块是否开启，OLED 排线是否松动。若仅有乱码，尝试按复位键重启。

**Q: 按键没有反应或按错键？**
A: 矩阵键盘扫描需要稳定接触，请确保按键按到底。若经常出现连键，属于物理按键抖动，已在软件中做消抖处理，正常使用即可。

**Q: 游戏过程中突然死机？**
A: 极小概率出现极端内存溢出保护，直接按下复位键重启设备即可，不影响存档数据。

## 七、硬件接线（按此接最稳）
- I2C1（软件 I2C，OLED）：SCL=P0.0，SDA=P0.1
- OLED SSD1306（I2C1）：SCL=P0.0，SDA=P0.1
- AT24C02（I2C3）：SCL=P2.1，SDA=P2.0（A0/A1/A2 接地时器件地址为 0xA0/0xA1）
- 4x4 矩阵键盘：
  - 行线：P1.7、P1.6、P1.5、P1.4
  - 列线：P1.3、P1.2、P1.1、P1.0
- 重要：P0 口为开漏，I2C1 的 SCL/SDA 必须外接上拉（4.7kΩ~10kΩ）。
- 蜂鸣器：P2.5

##  3，程序区压缩说明（51 适配）
- 目标：在不破坏核心玩法（迷雾、技能、两档难度、掉电最高分）的前提下，把程序压进 8051 可用程序区。
- 已做的压缩策略：
  - 移除向日葵整套功能（建造、技能、产出、显示与文档），保留射手/坚果墙/铲除三工具。
  - 难度由三档收敛为两档（EASY/HARD），减少菜单与分支逻辑，顺便解决难度选择跳变问题。
  - UI 文案和显示逻辑做轻量化，优先保留关键信息显示。
  - 输入与战斗逻辑做结构精简，删除高占用但非核心的冗余分支。
- 贡献重点：
  - 在“功能完整性”和“程序区限制”之间做取舍，优先保留可玩性与稳定性。
  - 保留并强化关键体验：射手近距离命中兜底、迷雾索敌限制、僵尸啃食提示音、最高分 EEPROM 持久化。
  - 文档与代码同步更新，确保后续维护者能理解压缩原因与设计边界。
