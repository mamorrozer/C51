# QG 51 塔防游戏（简化版植物大战僵尸）

## 1. 硬件连接建议
- I2C 总线（软件 I2C）：SCL=P0.0，SDA=P0.1（OLED / AT24C02 / PCF8591 共线）
- OLED SSD1306（I2C）：SCL=P0.0，SDA=P0.1
- AT24C02（I2C）：SCL=P0.0，SDA=P0.1
- PCF8591（I2C ADC）：
  - A0/A1/A2 建议接 GND（默认地址 0x90/0x91）
  - SCL=P0.0，SDA=P0.1
  - CH0 -> HW504 VRx（X轴），CH1 -> HW504 VRy（Y轴）
  - HW504 按压键 SW -> P3.3（低电平按下）
- 重要：P0 口为开漏，SCL/SDA 需外接上拉电阻（常用 4.7k~10k）。
- 蜂鸣器：P3.7

## 2. 按键映射（HW504）
- 摇杆方向：上/下/左/右移动光标（2/8/4/6）
- 摇杆按下（中键）：放射手（5，消耗40资源）
- 摇杆按下 + 上：放坚果墙（9，消耗30资源）
- 摇杆按下 + 下：铲除植物（10）
- 摇杆按下 + 左：暂停/继续（13）
- 摇杆按下 + 右：返回（16，在游戏中可直接结束）

## 3. 游戏规则
- 3 条轨道，敌人从右向左移动
- 植物：
  - `W` 坚果墙：高血量，专门阻挡
  - `S` 射手：会自动发射 `*` 子弹
- 敌人：
  - `z` 普通敌人（慢，血高）
  - `Z` 快速敌人（快，血低）
- 子弹与敌人同格时命中，敌人血量归零后消失并加分
- 敌人到达最左侧会扣基地生命 `H`
- 生存到目标时间判定胜利，生命归零判定失败

## 4. 编译说明（Keil C51）
1. 新建 Keil 工程（STC89C52/AT89C51）
2. 把本目录全部 `.c/.h` 加入工程
3. `main.c` 作为入口编译下载
